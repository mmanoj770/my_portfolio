# IoT & Connectivity — Smart Home Automation (code)

Source code for the five IoT session tasks documented at **/iot** on my portfolio.
Each folder is self-contained and is linked from the matching task page.

| Task | Folder | What's inside |
|---|---|---|
| 1 · ESP32 Web Server & HTML LED Control | [`task1-esp32-web-server`](task1-esp32-web-server) | ESP32 sketch serving the LED Control page + `index.html` |
| 2 · Adafruit IO Dashboard & MQTT | [`task2-adafruit-io-mqtt`](task2-adafruit-io-mqtt) | MQTT subscriber sketch driving a relay + 230 V bulb |
| 3 · IFTTT + Adafruit IO Automation | [`task3-ifttt-automation`](task3-ifttt-automation) | Same firmware, IFTTT applet settings, webhook test script |
| 4 · Firebase IoT Monitoring Dashboard | [`task4-firebase-dashboard`](task4-firebase-dashboard) | ESP32 firmware, login + dashboard pages, database rules & structure |
| 5 · Firebase Logging, Automation & Data Export | [`task5-logging-automation`](task5-logging-automation) | Logging/automation firmware, LDR calibration sketch, dashboard with chart + CSV |

All Wi-Fi passwords, API keys and account credentials are replaced with `YOUR_...` placeholders.
